# dsh-conversation-tree

> A workspace-wide conversation-tree view for DeepSeek Harness: every conversation and every branch in one place, with its source turn, its own usage, and one place to archive or delete it.

把工作区里的所有对话和由它们派生出的分支放在同一页管理：每条对话在自己的画布区域里画一棵树，所有对话共用一块可以拖拽、缩放的画布。分支不是旁聊窗口，而是普通 DSH 会话：拥有完整的模型、工具和斜杠命令，同时保留“从哪条对话、哪一轮、哪句话分出来”的关系。

## 功能

- **会话主视图新增「对话树」标签（工作区视图）**
  打开任意对话的「对话树」，看到的是**这个工作区里的全部对话**：每条对话在共享画布上占一块自己的区域，上方是标题行（标题、分支数、运行/归档状态、最近活动、收起箭头），下面就是这棵树本身。当前对话排在第一位，标题和节点用蓝色标出；其余按打开页面时的最近活动排序，页面打开期间别的对话继续活动也不会让树跳动，新出现的对话追加在末尾。从来没有分过支的对话也以单节点出现，节点下方提示“还没有分支”。

- **每棵树的画法沿用单树画布**
  根在上、分支向下、同层横向铺开；单击选中、双击打开、节点可折叠。所有树共享同一个坐标系：拖拽平移、滚轮/双指缩放、右下角缩放控件、一键适应画布和键盘操作都作用于整块画布，而不是各自独立的小画布。

- **画布怎么分配**
  默认单列：树从上往下读最自然。只有多列能明显提高“整块画布同时放得下”时的缩放比例，才会切成 2–4 列（按高度均衡分组，保持当前对话在左上第一块、其余顺序不变）。分支特别多的对话可以点标题行左侧的箭头单独收起，只留标题行；再次点击展开。搜索或刷新不会改变已摆放的位置。

- **工作区级查找、折叠与归档筛选**
  头部搜索框跨所有树按标题和分支点片段匹配：命中的节点高亮、其余节点和整棵树变暗，第一个命中自动居中并选中；每棵树可单独收起；已归档的对话和子树默认隐藏，头部按钮可临时显示。头部计数显示当前工作区的对话数和分支数；对话过多时只保留最近 300 个并提示。

- **键盘操作**
  画布可聚焦：方向键按画布位置切换节点、Enter 打开、`Home`/`End` 跳到首尾、`+`/`-` 缩放、`f` 适应画布、`Esc` 退出搜索。

- **选中节点后显示完整信息**
  侧栏包含标题、来源对话、分支轮次、层级、分支点摘要、本会话轮次与步数、token 明细、缓存命中率、模型和工作区。节点单击选中，双击或点击侧栏按钮打开会话。选中任意一棵树里的节点都会显示同一份信息。

- **消息底部的「对话树分支」入口**
  在任意已完成轮次创建子会话。子会话继承该轮之前的上下文，并在会话头记录父会话；插件另存分支轮次和分支点摘要。

- **带回（bring back）**
  根对话和分支都可以选择一个目标对话。插件只压缩来源会话自身的轮次（跳过 fork 继承的前缀），先给出可编辑的摘要预览，确认后再以排队消息送入目标会话；来源会话保留。输入框下方也提供同尺寸的「带回」入口。

- **归档与删除子树**
  侧栏底部提供归档和删除。节点有子分支时明确提示影响数量，确认后连同子树一起处理；归档运行中的节点会先确认是否会停止其活动。删除只针对本插件创建的分支，根对话不在此处删除。处理进度显示在树页头部，不占用聊天页的全局提示。

- **对话树页是管理页**
  打开「对话树」时原生输入框隐藏，页面只用于查看和管理会话。

## 安装

在 DSH Web 的 **设置 → 插件** 中使用 Plugin Manager 的「安装本地 Bundle」，选择本目录。

也可以在目标 profile 中链接本目录：

```powershell
dsh plugin --profile <profile> add <path-to-this-directory>
```

随后把 `dsh-conversation-tree` 加入该 profile 的 `dsh.profile.bundles`。更新插件代码（`client.js` 或 `index.js`）后需要重启 DSH，再刷新 Web 页面。

## 使用

1. 打开一条对话，滚动到需要分叉的轮次。
2. 点击消息底部的「对话树分支」。
3. 新分支打开后，点击顶部的「对话树」标签：这个工作区的所有对话都会画在同一块画布上，当前对话排在最左上。
4. 在任意一棵树里单击节点查看来源、轮次、token 和模型；双击节点打开该对话。
5. 拖拽空白处平移，滚轮或双指缩放；点右下角的适应按钮回到全局；分支特别多的对话点标题行箭头收起。
6. 在侧栏或输入框下方点击「带回」，选择目标对话并确认摘要。
7. 在侧栏底部归档或删除分支；根对话不显示这两个操作。

## 数据与安全

- 树关系保存在 `$DSH_HOME/conversation-tree.json`，这是一个带跨进程锁和原子替换的轻量注册表。锁目录记录持有者 pid、主机与时间，持有进程退出后会被自动回收。
- 每个分支还会在自身的会话日志中写入一条 `plugin:conversation-tree/edge` 记录；注册表丢失或损坏时，打开分支会从会话日志恢复祖先链。
- 会话头中的 `SessionHeader.parentSession` 同时记录父会话，可与注册表相互核对。
- 创建分支与删除子树在同一个 Host 进程内串行执行，避免“刚登记 pending 就被删除”和“删除过程中又挂上新子分支”的竞态。
- 工作区视图由客户端把该工作区的会话 id 交给 `POST /forest`，Host 回报这些会话所属的连通分量（含祖先、兄弟和后代），因此单条分支不会因为没有父节点而被误画成根。
- 用量只统计会话自身拥有的事件：读取时跳过 fork 继承的前缀，因此新分支不会复制父会话的 token 数；轮次与步数按同一规则计算。冷会话统计带 30 秒缓存，并以 4 路并发读取。
- 摘要调用限制 64KB 请求体和 180 秒超时，客户端取消会中止生成；同一来源的并发请求复用同一次调用。摘要不设输出 token 上限，篇幅由内容决定；记录以数据边界包裹并做常见密钥格式脱敏，生成结果先进入可编辑预览。
- 创建、压缩、删除与工作区读取路由会校验浏览器 `Origin` 与 `Host` 请求头一致（连接层交给插件的是以 `http://dsh.internal` 为基址的合成请求，不能拿它与 `Origin` 比较），作为连接层同源围栏之外的第二道防线。
- 删除只接受本插件登记的分支，并校验会话目录、日志与锁，仅移除经过验证的 JSONL 会话文件。
- 删除成功后会 `detach` 对应 workspace，并清理归档与置顶集合；插件启动时对失效 id 做一次 reconcile，避免已删除会话残留在列表中。
- 插件重载或页面刷新后，原生 UI 可能重新 resume 分支，产生没有插件 handle 的 live agent。删除时会先 cancel、等待 idle，再释放其 scope 并移除注册表条目。
- 删除目前只对 macOS 与 Windows 上已验证的 JSONL 后端开放；其他平台仍可创建、查看和带回，删除会被明确拒绝。
- 根对话不能在本页删除；分支归档使用 DSH 原生归档，可取消。

## 已知限制

- 原生消息底部的分支图标创建的是未登记的普通分支；本插件的树只管理通过「对话树分支」创建的会话。这样无需依赖或改写 DSH 内部的 `ctx.sessions.fork`，升级更稳定。
- 分支会话同样出现在普通会话列表中；树是额外的管理视图，不隐藏系统会话。
- 工作区视图按当前会话所属的工作区取范围；会话不属于任何工作区时退回为它自己那棵树。一次最多带入 300 个会话（当前会话优先），超出部分会提示。
- 一棵树来自同一个根：如果某个分支被移动到了别的工作区，它的根和同层分支仍会出现在这棵树里，因为那是它真实的血缘。
- 删除使用中的分支时插件会先停止它；若另一个进程持有该会话的写锁，可能返回“删除没有完全成功”，失败项保留在树中并可重试。
- 分支标题由父标题自动生成，之后可在 DSH 中重命名；节点只显示最后一段分支名，完整标题在侧栏。
- 移动端树改为单列、画布上下左右拖拽；树多时初始缩放会很小，需要放大或收起部分树后查看。
- 真正的按用户授权依赖 DSH 连接层暴露调用者身份；当前只做到同源校验与请求体上限。

## 开发

```powershell
node --test conversation-tree.test.js client.test.js branch.test.js
```

Host 路由：

- `POST /api/conversation-tree/branch`
- `GET  /api/conversation-tree/tree?sessionId=...`（加 `&stats=1` 时附带该会话自身的 token / 轮次统计）
- `POST /api/conversation-tree/forest`（`{ sessionIds, stats }`，返回工作区内每条对话所属的完整连通树）
- `POST /api/conversation-tree/summarize`
- `POST /api/conversation-tree/delete`

## 兼容性

- DSH `>=0.2.2-rc.1 <0.3.0`
- 删除功能仅支持 macOS 与 Windows 上已验证的 JSONL 会话后端。
