# 对话树 · dsh-conversation-tree

把一条对话和它的所有分支组织成一棵可缩放的树。分支不再是散落的旁聊窗口，而是普通 DSH 会话：拥有完整模型、工具和斜杠命令，同时保留“从哪一条对话、哪一轮、哪句话分出来”的关系。

## 功能

- **会话主视图新增「对话树」标签**  
  根对话在上，分支向下展开；同层分支横向铺开，不再挤在画布右侧一列。小节点显示分支名、轮次和自身 token 用量。画布可拖拽、滚轮或双指缩放，右下角可放大、缩小或一键适应画布；窄屏自动改为缩进列表，避免把整棵树压成不可读的小字。

- **查找、折叠、只看未归档**  
  头部搜索框按标题和分支点片段过滤：命中的节点高亮、其余变暗，第一个命中自动移到画布中心。有子分支的节点右侧有折叠箭头，折叠后显示“还有 N 个分支”。归档过的子树默认隐藏，头部归档按钮可以临时显示它们。

- **键盘也能操作**  
  画布可聚焦：方向键切换节点、Enter 打开、`Home/End` 跳到首尾、`+`/`-` 缩放、`f` 适应画布、`Esc` 退出搜索。

- **节点选中后，右侧显示完整信息**  
  侧栏显示标题、来源对话、分支轮次、层级、分支点提示词、本对话轮次/步数、token 明细、缓存命中率、模型与工作区。节点单击选中，双击或侧栏按钮打开对话。

- **消息底部的「对话树分支」入口**  
  在任意已完成轮次创建子会话。子会话继承该轮之前的上下文，并在会话头里记录父会话；插件另外记录分支轮次和分支点摘要。

- **带回任意对话**  
  根对话和分支都能选择树里的另一个对话作为目标。插件只压缩来源对话自己的轮次（跳过继承前缀），先给出一份可编辑的摘要预览，确认后才以排队消息送入目标对话；来源对话保留。输入框下方有一个与原生统计胶囊同尺寸的「带回」入口。

- **归档 / 删除整棵子树**  
  侧栏底部提供归档和删除。节点有子分支时会明确提示“下面还有 N 个分支”，确认后连同子树一起处理。删除只针对本插件创建的分支；根对话不在这里删除，避免误删原始对话。删除过程显示在树页头部（“正在删除…” → “已删除 N 个对话”），不再用会飘到聊天页的全局提示；删除完成后同时清理注册表、会话文件和 workspace 记账，避免会话列表留下幽灵行。

- **对话树页是管理页**  
  打开「对话树」时原生输入框会隐藏，页面只用于查看和管理对话，不再出现“发消息 / 创建任务”。

- **不迁移旧旁聊**  
  这是独立的新插件。旧的旁聊会话仍按普通会话存在，不会自动进入树；确认不需要后可以从会话列表归档或清理。

## 安装

在 DSH Web 的 **设置 → 插件** 里使用 Plugin Manager 的「安装本地 Bundle」，选择本目录。

也可以在当前 profile 中手动加入链接：

```powershell
dsh plugin --profile web add G:\workspace\dsh-conversation-tree
```

然后把 `dsh-conversation-tree` 加入 profile 的 `dsh.profile.bundles`。安装后刷新 Web 页面；Host 侧改动需要重启 DSH。

## 使用

1. 打开一条对话，滚到想分叉的那一轮。
2. 点消息底部的「对话树分支」。
3. 新分支打开后，点顶部的「对话树」标签。
4. 单击节点，在右侧查看来源、轮次、token 和模型；双击节点或点「打开对话」进入。
5. 在侧栏点「带回」把这条对话的讨论送入另一条对话；在输入框下方也可以直接点「带回」。
6. 在侧栏底部归档或删除分支；根对话不会显示这两个操作。

## 数据与安全

- 树关系保存在 `$DSH_HOME/conversation-tree.json`；这是一个带跨进程锁和原子替换的轻量注册表。锁目录记录持有者 pid 与时间，持有进程崩溃后会被自动回收，不需要手动删目录。
- 每个分支还会在自己的会话日志里写一条 `plugin:conversation-tree/edge` 记录。注册表丢失或损坏时，打开分支会从会话日志把祖先链恢复出来。
- 分支会话的父关系同时写入不可变的 `SessionHeader.parentSession`，即使注册表丢失也能从会话头核对。
- 创建分支与删除子树在同一个 Host 内串行执行，避免“刚登记 pending 就被删掉”和“删除过程中又挂上新子分支”的竞态。
- 用量只统计会话自己拥有的事件：读取时跳过 fork 继承的前缀，所以新分支不会复制父对话的 token 数。轮次和步数也按同一前缀计算。冷会话的统计有 30 秒缓存，并按 4 个并发读取，刷新大树不再串行重读所有日志。
- 摘要调用有 64KB 请求体上限、800 token 输出上限和 60 秒超时，客户端取消会中止生成；同一来源的并发请求复用同一次调用。记录以数据边界包裹并做常见密钥脱敏，摘要先生成可编辑预览再发送。
- 写路由（创建、压缩、删除）会校验 `Origin` 与请求 host 一致，作为连接层同源围栏之外的第二道防线。
- 删除只接受本插件创建的分支记录，并校验会话目录、日志和锁，只移除经过验证的 JSONL 会话文件。
- 删除成功后会 `detach` 对应 workspace，并清理归档/置顶集合；插件启动时还会对旧版本遗留的失效 id 做一次 reconcile，避免“提示已删除但列表还在”的幽灵会话。
- 插件重载或页面刷新后，原生 UI 可能重新 resume 分支，产生一个没有插件 handle 的 live agent。删除时会先 cancel、等待 idle，再释放其 scope 并移除注册表条目，所以这类分支仍可删除。
- 当前只对 macOS 和 Windows 的已验证 JSONL 后端开放删除；其他平台仍可创建、查看和带回，删除会明确拒绝。
- 根对话不能在本页删除；分支的归档使用 DSH 原生归档，可取消。

## 已知限制

- 原生消息底部的分支图标仍会创建一个“未登记”的普通分支；本插件的树只管理通过「对话树分支」创建的分支。这样不会依赖或改写 DSH 的内部 `ctx.sessions.fork`，升级更稳。
- 分支会话仍会出现在普通会话列表中；树是额外的管理视图，不隐藏系统会话。
- 删除正在使用中的分支时，插件会先停止它；如果另一个进程正持有该会话的写锁，仍可能返回“删除没有完全成功”，失败项会保留在树里，可重试。
- 分支的标题由父标题自动生成，后续可在 DSH 中重命名；节点只显示最后一段分支名，完整标题在侧栏。
- 在手机上，画布和详情上下排列；树改为缩进列表，详情区内部滚动，较大的树可用缩放/拖拽查看。

## 开发

```powershell
node --test conversation-tree.test.js client.test.js branch.test.js
```

Host 路由：

- `POST /api/conversation-tree/branch`
- `GET  /api/conversation-tree/tree?sessionId=...`（加 `&stats=1` 时附带该会话自己的 token / 轮次统计）
- `POST /api/conversation-tree/summarize`
- `POST /api/conversation-tree/delete`
